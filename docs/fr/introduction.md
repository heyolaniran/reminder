Calendrian est un moteur puissant conçu pour vous aider à atteindre votre audience directement sur leurs écrans de verrouillage via des notifications de calendrier.

En intégrant Calendrian dans vos propres systèmes, vous pouvez automatiser les rappels d'événements, les lancements de produits ou toute communication sensible au temps avec une visibilité extrêmement élevée.

## Fonctionnalités Clés

- **Visibilité Directe** : Contournez les boîtes de réception et les filtres anti-spam.
- **Confidentialité Local-First** : Utilisation de clés cryptographiques et du stockage local pour gérer l'identité.
- **Planification** : Envoyez des notifications immédiatement ou planifiez-les pour le futur.
- **Aperçus de l'Engagement** : Suivez qui a accepté, décliné ou est incertain pour votre événement.

## Commencer

Pour commencer à utiliser l'API Calendrian, vous aurez besoin de :
1. Une **Clé d'Accès Maître** (obtenue en soutenant le projet sur le tableau de bord).
2. Un **Refresh Token Google** (si vous souhaitez envoyer des rappels depuis votre propre compte).
